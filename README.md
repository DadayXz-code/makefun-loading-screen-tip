A single loading-screen tip, 146 characters, for stressed developers and the AI coding agents building beside them: when the build looks stuck, one of you is reasoning and the other is just tired — and only one of you never sleeps. `main.py` writes that one line, and nothing else, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
